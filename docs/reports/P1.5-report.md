## Implemented in P1.5

- ADR-0003 fixes Windows x64/macOS ARM64. No unsupported build, signing, notarization or release job.
- Native menu adapter; platform-neutral existing Core and CLI; developer PowerShell dependencies
  documented separately from application requirements.
- WebContentsView preview and reviewed HTML Lab fixture, separate private nonpersistent Sessions,
  no guest preload/Node/editor bridge. Network, scripts, windows, downloads and permissions denied.
- Native bounds sync, split resize, minimized/restore visibility, shell modal exclusion and explicit
  guest disposal. At most two live tabs with reusable mode Sessions.
- Pure escaped Core HTML/CSS/SVG renderer in the existing renderer package. Stable-ID inspection,
  current-revision diagnostics, bounded PNG capture and operation audit through strict named tools.
- Existing trusted sender/main-frame/exact-URL IPC gate retained; bridge explicitly becomes 1.2.0.
  Existing desktop mutations and CLI demo still use Core Dispatcher; no new document write path.
- Three distinct IA directions with four workspaces each; Light/Dark/System and platform hints;
  tokens, typography, focus, menus, shortcuts, layer tree, inspector, docking and palette specs.
  This is a standalone editable wireframe, not a production editor or Figma implementation.
- Existing five requested frontend capabilities found; no duplicate install. Radix/shadcn evaluated
  as candidates, neither added. Two scoped project skills supplied in the UI PR.
- QA handle/write permission verified; Issue #18 assigned and CODEOWNERS/collaboration aligned.
  Corrected the overview's inaccurate claim that persistent storage was implemented in P1.

high-DPI allocation stress safety. Audit is an in-memory ring, not a durable security log.
