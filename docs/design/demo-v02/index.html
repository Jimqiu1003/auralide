用同一段流程，感受差异。

切换幻灯片 → 选择文字 → 修改并应用 → 选择形状 → 在「排列」调整尺寸 → 模拟保存 → 再编辑并模拟重开 → 切换 Aura → 返回编辑器。

这是视觉与交互原型。

编辑、撤销、保存与打开仅在本页内存中模拟，刷新即丢失。没有 Agent 服务、真实文件读写、联网研究或发布能力。Aura 使用受限 iframe 模拟，正式应用安全架构不受修改。
